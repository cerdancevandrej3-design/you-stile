# Админский доступ к сайту

## Как войти как администратор

### Способ 1: Через URL параметр (рекомендуется)
Просто добавьте параметр `?admin=stilist2026` к адресу сайта:

```
https://stilist-ai.ru?admin=stilist2026
```

После этого:
- Система проверит пароль
- Если пароль верный, сохранит статус админа в браузере
- Уберёт параметр из URL
- Теперь вы можете пользоваться всеми тарифами **бесплатно**

### Способ 2: Изменение пароля
Если хотите сменить пароль администратора, отредактируйте файл `.env` на сервере:

```bash
ssh -i ~/.ssh/id_rsa_deploy root@186.246.31.126
cd /var/www/you-stile/you-stile
nano .env
```

Найдите строку:
```
ADMIN_PASSWORD=stilist2026
```

Измените на свой пароль и перезапустите:
```bash
pm2 restart stilist
```

## Как работает админский доступ

1. **Вход**: При переходе по ссылке с параметром `?admin=пароль` система проверяет пароль через API
2. **Сохранение**: При успешной проверке статус сохраняется в `localStorage` браузера
3. **Bypass оплаты**: При клике на любую кнопку "Выбрать тариф" система:
   - Проверяет, есть ли админский доступ
   - Если да — сразу открывает модальное окно стилизации (минуя оплату)
   - Если нет — показывает окно выбора тарифа и оплаты

## Очистка админского доступа

Если нужно выйти из админского режима:
1. Откройте консоль браузера (F12)
2. Выполните:
   ```javascript
   localStorage.removeItem('admin_access');
   location.reload();
   ```

Или просто очистите все данные сайта в настройках браузера.

## Безопасность

- Пароль передаётся только один раз при первом входе
- После проверки пароль удаляется из URL
- Статус админа хранится локально в браузере
- На сервере пароль хранится в `.env` файле (не в git репозитории)

## Доступ к админ-панели промокодов

Панель управления промокодами доступна по адресу:
```
https://stilist-ai.ru/api/admin?secret=admin
```

Где можно:
- Генерировать новые промокоды
- Просматривать список всех кодов
- Видеть статистику использования
