## nails.csv — База дизайнов ногтей

**Файл:** `nails.csv/Новая таблица - Лист1 (1).csv`
**84 дизайна** (STIL-26-001...STIL-26-084)

### Структура (9 колонок)
1. ID — артикул (STIL-26-001 ... STIL-26-084)
2. Название RU/EN
3. Цвет базы
4. Акцентный цвет
5. Третий цвет/деталь
6. Техника
7. Сезон
8. Описание RU
9. **Промпт EN** — готовый macro-photography промпт для генерации

### Категории в базе
- Космос/галактика (Cat-Eye, ауры)
- Животные принты (леопард, крокодил, змея)
- Камень/минералы (мрамор, нефрит, рубин, янтарь)
- Металл/хром
- 3D-капли, аквариумные дизайны
- Асимметрия/Тигухагу (две разные руки в одном кадре)
- Французский маникюр (крокодил, неоновый, хром)
- Минимализм
- Неон/киберпанк

### НЕОБХОДИМО ДЛЯ ИНТЕГРАЦИИ

### Промпты для генерации
Каждый дизайн имеет готовый английский промпт в колонке 9.
Пример: "macro photography of female hands, elegant long fingers, high-end jewelry, soft cinematic lighting. Almond nails featuring..."

### Генерация картинок
- Скрипт: `generate-nails.mjs`
- Модель: `openai/gpt-5.4-image-2`
- Разрешение: 2K
- Формат: 3:4 вертикаль
- Цена: ~581₽ за 84 дизайна

### ВАЖНО для промптов генерации
1. ДЛИННЫЕ ногти — короткие ногти не создают вау-эффекта. Обязательно добавлять "LONG" или "EXTRA LONG" в промпты
2. ДВЕ РУКИ для дизайнов Тигухагу (mismatched) — в одном кадре
3. Реалистичная кожа — поры, волоски, складки на сгибах
4. Softbox свет — профессиональный свет как у OPI/Chanel

### Планы интеграции
1. Добавить колонки в CSV (Форма, Длина, Повод)
2. Перегенерировать картинки с правильными промптами
3. Вариант C: каталог с blur-превью + HD по регистрации
4. Мастера маникюра: подписка ~500₽/мес + лиды

## Тарифы

- **Стандарт 100₽** — 1 фото + рост/вес → 3 случайных образа
- **Премиум 200₽** — до 3 фото + поводы + бюджет + астро → до 5 образов
- **Оцени стиль (бесплатно)** — фото в полный рост + рост/вес → оценка 1-10
