# Hermes — авто-публикатор канала

Три раза в день публикует в Telegram короткие посты:
**Уход → Гардероб → Психология** + яркая AI-обложка.

**План дня (Москва):**
- **10:00** — женщины
- **14:00** — женщины
- **19:00** — мужчины

**Формат каждого поста:** крючок-заголовок + 3 коротких раздела + CTA.  
Язык: **только русский** (без украинских/смешанных форм).

## Стек
- Node.js 22 + TypeScript (tsx)
- Polza AI: текст + картинка
- Telegram Bot API
- node-cron (Europe/Moscow)

## Запуск
```bash
cd hermes
npm i
cp .env.example .env   # заполни ключи
DRY_RUN=true npm run test-once -- --audience=women
npm start
```

## Если пост не вышел
Гермес **не ищет новости заново**. Текст уже сохранён: через 8–15 минут он только догенерирует недостающие фото (сначала GPT Image, если снова сбой — Qwen Image 2, она хорошо пишет бренды) и выкладывает в канал. Проверка каждые 10 минут, до 5 попыток.

Принудительно: `npx tsx hermes.ts --retry-pending`

## Telegram
- Бот: **Hermes Stilist Bot** — токен в `hermes/.env`
- Канал: `@stilist_ai_ru`
НЕ путать с `@Alex_tel_12bot`

## Формат новостей в канале
- Без видимых HTML-тегов. Жирный/курсив через `parse_mode=HTML`.
- Три новости разными цветами: 🟥 🟨 🟩 (в Telegram нет цветного шрифта).
- Мнение стилиста — блок с полоской, не ответ на альбом.
- Текст не слать reply на фото.
