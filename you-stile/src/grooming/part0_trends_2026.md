# Большой каталог: стрижки, цвет, тонирование (2026)

Стилист ОБЯЗАН брать конкретное имя из списков ниже. В платном пакете — три разных имени, не вариации одного каре. На кадре «после» всегда: форма + свет у лица + укладка (blowout / glass / soft waves).

Запрет: «чуть подровнять», «натуральный русый», пепел из коробки, плоский каштан, видимая лесенка 2010, wolf на тонких, French bob круглому лицу.

---

## СТРИЖКИ ЖЕНЩИНЫ — КОРОТКИЕ И КАРЕ (имя в look.name)

1. **Italian bob** — ниже подбородка, тяжёлый периметр, объём, глянец. 25–55, овал/круг/квадрат (мягкие концы). Не тонким без укладки.
2. **French bob** — по подбородок + часто чёлка. Овал, сердце, тонкие. **Не круглому.**
3. **Boyfriend bob** — челюсть–ключицы, ношеные концы. 18–40, густые. Не тонким, не «гладко-дорого» (тогда Italian).
4. **Butterfly bob** — крылья у лица в длине каре. Густые, овал/вытянутое. Не тонким, не мелкому кругу.
5. **Graduated / stacked bob** — короче сзади, длиннее спереди. Овал, сердце. Не круглому с объёмом у щёк.
6. **A-line bob** — чёткая диагональ вперёд. Овал, квадрат с мягким концом. Не очень тонким.
7. **Blunt quiet-luxury bob** — ровный глянцевый рез. Овал, густые. Тонким — только если нужен эффект густоты + gloss.
8. **Shaggy bob** — воздушный, не панк. Волна, 18–35. Не 45+ тонким.
9. **Bixie** — боб×пикси. Овал, мелкие черты, смелые.
10. **Soft pixie** — текстура макушки, не ёжик. Овал/сердце/вытянутое, форма черепа. Не круглому короткому боку.
11. **Long pixie / grown-out pixie** — переход к каре. Кто отращивает.
12. **Micro-bang French** — короткая чёлка + каре. Только овал/сердце, густые, смелые 18–30. Не низкий лоб, не круг.
28. **Octopus cut** — короткие щупальца у лица + длинный низ. Густые, 18–35. Не тонким, не круглому короткому боку.
29. **Lychee / bubble bob** — округлый объём, концы внутрь. Овал, сердце. Не квадратной челюсти без мягких концов.
30. **Jellyfish cut** — два яруса, верх короче. Только густые + смелые 18–30. Не 40+, не тонким.
31. **Hush cut** — невидимые слои, снаружи одна линия. Густые, кто боится короткого. Тонким нельзя.
32. **Modern shag + bottleneck bangs** — воздух + узкая чёлка у пробора. Волна, овал/вытянутое.
33. **Shoulder U-cut** — мягкая U по плечам, не острый V. Универсально 25–50.
34. **Glass middle-part lob** — прямой пробор, зеркальный глянец, ключица. Овал, густые прямые.
35. **Volume-crown tuck** — объём макушки, пряди за уши, длина ключица–плечи. Круглому (вертикаль).
36. **Korean husky layers** — много воздуха, не лесенка 2010. Средние/густые, 18–40.
37. **Spanish cascade** — длинные слои от скул, концы тяжёлые. Густые волны.
38. **Rounded French with wispy** — каре + воздушная чёлка. 35+, тонкие (чёлка wispy).
39. **Clavicle blunt with curtain** — тупой срез ключица + шторки. Тонким даёт густоту.
40. **Long curtain money-piece** — длина ниже лопаток + шторки + свет у лица. Если не тонкие сосульки.

## СРЕДНИЕ


13. **Collarbone lob** — ключица, невидимые слои. Универсальный вау, особенно круг и 30+.
14. **Lived-in lob** — тот же ключичный, воздух, air-dry. Волна 18–40.
15. **Long bob (mid-neck)** — между каре и ключицей. Квадрат, сердце.
16. **U-shape long bob** — мягкая U, не острый V. Длиннее ключицы, густые.
17. **Face-framing lob** — короче у лица, низ полный. Сердце, квадрат.
18. **One-length lob** — одна длина, тупой конец. Тонким (даёт густоту). Не густым без внутренних слоёв (пирамида).

## ДЛИННЫЕ (только с формой)

19. **Invisible / hush layers** — снаружи одна длина. Густым, кто не режет. **Тонким нельзя.**
20. **Butterfly cut** — крылья + длинный низ. Густые, 18–40. Не тонким.
21. **Soft wolf** — без мулета. Густые, волна, 18–35. Не круглому, не 40+ «чисто».
22. **Long shag** — перьевые слои, не ступени. Густые, характер.
23. **90s blowout layers** — объём короны, концы тяжёлые, journal blowout. 25–45, средние/густые.
24. **Face-frame long** — длинные + короче у скул + свет. Универсально, если не тонкие сосульки.
25. **Blunt long (one length)** — ровный тяжёлый срез. Только густые прямые + glass. Тонким — запрет (шнурки).
26. **Curly butterfly / dry-cut curls** — стрижка по завитку, не мокрый каскад. Кудри 2–3.
27. **Curly bob / curly shag** — длина каре/плечи по завитку.

## ЧЁЛКА (добавка к любой длине)

- **Curtain 2026** — к скулам, перья. Почти всем; круглому до скул, не до бровей.
- **Wispy / see-through** — воздух. 35+, тонкие.
- **Side-swept** — квадрат, ромб.
- **Bottleneck bangs** — узкие у пробора, шире к скулам. Овал, вытянутое.
- **Blunt bangs** — только овал/сердце, густые, не низкий лоб, не круг.

## МУЖЧИНЫ

Textured crop, French crop, Caesar, mid fade + texture, low taper crop, messy quiff (густые), buzz #2–#3, bald fade, clean shave. Longer top — только если в проборе нет кожи. Не combover.

## ОКРАШИВАНИЕ — РЕЦЕПТЫ (имя в hairColor)

**Брюнет:** expensive espresso, mocha silk, chocolate melt, cola brunette, dark cherry cola, milk-tea brown, dirty chai, chocolate chrome, soft black с бликом (только зима/контраст), mushroom brown (лето).
**Русый/bronde:** richer bronde, beige brown, caramel dimension, honey melt, salted caramel, latte blonde-brown, taupe brown.
**Блонд (обязательно держать в пуле — не только каштан):** butter blonde, teddy blonde, Bessette cream, champagne beige, vanilla cream, wheat, scandi blonde, sandy beige, honey gold, strawberry blonde (весна), pearl toner (только холодное лето/зима с бровями), lived-in blonde + shadow root. Не платина за один раз с тёмной базы. Не пепел на тёплом лице.
**Медь:** cinnamon copper, apricot copper, terracotta, strawberry copper (весна), sunset copper, ginger spice. Не пакетный рыжий холодной коже.
**У лица:** money piece + melt, copper money piece, face-frame +1–2, babylights у пробора, icy-beige ribbons (только холодный цветотип).
**Седину 40+:** gray blending, soft highlights, pearl blend, не чёрная каска.
**Техники:** AirTouch, soft balayage, foilyage (длина), highlights + lowlights, dimensional drench (насыщенный монохром + gloss, не плоский тюбик), root melt, gloss glaze.

**Paid — правило света:** из трёх looks минимум один светлее текущего (блонд / бронд / шампань / мёд / money piece / face-frame). Если полный блонд не идёт — карамельные или жемчужные блики, не третий espresso.

## ТОНИРОВАНИЕ И БЛЕСК (обязательный финиш «после»)

Тонирование — не «другой цвет», а умный финиш: закрыть кутикулу, убрать желтизну или зелень, добавить нюанс. На фото без gloss даже хороший цвет выглядит дёшево.

| Задача | Тонер / gloss | Кому | Нельзя |
|--------|---------------|------|--------|
| Жёлтый блонд | беж / шампань / нейтральный фиолет слабо | уже блонд | сильный фиолет → серо-сиреневый труп |
| Оранж на мелировании | пепельно-беж слабо или натуральный 7–8 | тёплая база | холодный пепел на тёплой коже |
| Зелень на тёмном | тёплый красно-коричневый / gold-brown | после пепла | ещё больше пепла |
| Тусклый брюнет | шоколадный / mocha gloss | почти всем брюнеткам | чёрный дренч на бледном |
| «Дорогое стекло» | clear gloss или тон в тон +1 блеск | всем на кадр | gloss вместо стрижки |
| Слишком пепел | золото / беж / карамель | серое лицо | ещё freeze ash |
| Медь потускнела | copper/cinnamon gloss | осень/весна | холодный тонер |
| Тёплый «желток» | нейтральный беж, не синий | славянская розовая кожа | |

**Shadow root / root melt:** 1–3 см глубины у корня, размытие. Отрастание выглядит дорого. Не путать с неряшливым отростком 4 см.

**Glaze раз в 4–8 недель** держит вау между окрашиваниями. В тексте look укажи: «тонирование + gloss», не только «покрасить».

## ВОЗРАСТНЫЕ ПОЛКИ (критично: бабушка и школьница — не одна полка)

### До 18 (школа, ~14 лет)
Вау = новая форма волос и блеск, не «взрослая женщина» и не ребёнок младше.
- Стрижка: длинные face-frame / curtain / collarbone / мягкий U-lob. Можно шторки.
- Нельзя: wolf, pixie, micro-bang, boyfriend «сексуальный», платина, сильная медь, осветление больше чем +1–2 у лица, чёрный дренч.
- Цвет: чаще gloss своих + лёгкий мёд/беж у лица. Любое осветление — только щадяще, мастер решает по базе, тон «школа, не салон-инстаграм».
- Лицо на фото: тот же возраст. Чище кожа, не −2 года во взрослую модель.
- Уход: умывание + крем + SPF. При прыщах — мягко (BHA слабо / ниацинамид). Без ретинола, кислот-курсов, подтяжек, блефаро.
- Макияж (paid, текст): бальзам, прозрачный SPF, максимум лёгкий блеск губ. Не вечерний soft glam, не стрелки, не контуринг.
- Одежда в кадре: свитер, рубашка, футболка с аккуратной горловиной. Не открытые плечи «гламур».

### 18–24
Смелее: boyfriend, butterfly, money piece, curtain. Лицо ~2 года свежее, взрослое.

### 25–34
Italian, collarbone, hush, butter/mocha. Лицо ~3–4 года моложе.

### 35–59
Ключица / Italian, шторки, свет у лица, volume blowout. Лицо ~5 лет свежее.

### 60+ (бабушка, мама мамы)
Вау = дорого и ухоженно в своём возрасте, не «перекрасили в 35».
- Стрижка: Italian bob, collarbone, мягкое каре, wispy, объём на макушке. Тонкие — тупой периметр, не слои-сосульки.
- Седина: gray blending ИЛИ серебро/седина как цвет + gloss (это тоже роскошь). Не чёрная каска, не пепел-труп, не платина с тёмной базы.
- Нельзя: wolf, boyfriend, money piece-платина, длинное полотно на тонких, pixie «под мальчика» без запроса.
- Лицо: свежее лет на пять, но всё ещё 60+, не 40 и не пластиковая кукла.
- Уход: барьер, SPF, крем для век, мягкий ретиноид только если кожа крепкая. Не кислоты каждый вечер. Подтяжку — только если по фото правда явно и с альтернативой.
- Одежда: блузка, кардиган, жемчуг/платок. Не клубный топ.

## УКЛАДКА НА ФОТО

Volume blowout · Glass sleek · Soft S-waves · Curtain part с подъёмом у корня. Не распущенные «как есть».

---

## ТЕХКАРТА ДЛЯ МАСТЕРА (обязательно в поле masterHowTo)

Клиент несёт этот текст в салон. Пиши по-русски, коротко, языком мастера: длина, периметр, слои, чёлка, пробор, цвет/тонер, укладка. Без процентов оксида и граммовок порошка (это решает колорист по базе). Без «просто подровнять».

Формат masterHowTo (4 блока, 8–14 строк):
1) СТРИЖКА — длина относительно лица (челюсть / середина шеи / ключица / лопатка). Периметр: тупой / мягкий / чуть disconnected. Внутри: невидимые слои / снять вес / не слоить тонкие. Чёлка: есть/нет, длина, куда впадает.
2) ЦВЕТ — что не трогать (база), что менять (лицо +1–2 / money piece / балаяж / только gloss). Melt у корня 2–4 см, без полосы.
3) ТОНЕР / GLOSS — направление: беж, шампань, mocha, корица… Не пепел, если лицо тёплое. Финиш gloss обязательно.
4) УКЛАДКА В САЛОНЕ — брашинг / glass / мягкая S-волна; какой пробор.

Шпаргалка по стрижкам:
- Italian bob: длина середина шеи или ниже подбородка, тяжёлый тупой периметр, вес снять ВНУТРИ, снаружи не лесенка. Боковой пробор. Брашинг от корня, концы чуть внутрь.
- French bob: по подбородок, периметр плотный. Чёлка по запросу, не круглому лицу. Не укорачивать до щёк.
- Boyfriend: ключица–челюсть, концы мягко рваные, не идеальная линейка. Текстура ножницами, не филировать в пыль.
- Butterfly / hush: короче у лица впадает в длину, НИЗ полный. Без полки-ступени. Тонким не делать.
- Collarbone lob: срез по ключице, тупой конец если тонкие, невидимые слои если густые. Не V-хвост.
- Curtain: пробор от макушки, длина к скулам, перья, впадают в боковые пряди. Круглому — длиннее, не до бровей.
- Pixie/bixie: текстура макушки пальцами, виски не брить в ноль круглому лицу.
- Мужской crop: fade mid, верх 4–7 см, чёлка вперёд, мат. Не гель-шлем. Просвечивает темя — короче, не длиннее.

Шпаргалка по цвету:
- Тёплый цветотип: беж/мёд/карамель/корица. Пепел запрещён.
- Холодная зима с тёмными бровями: mocha, холодный каштан, слабый жемчуг у лица, не серый шлем.
- Тусклые свои: gloss тон-в-тон + face-frame, не перекрашивать всё.
- Жёлтый блонд: тонер беж/шампань, не сильный фиолет.
- Седина: blending, не чёрный дренч.

Уход за лицом для клиента (homeHowTo, paid): утро и вечер по шагам «чем — куда — сколько ждать». Ретинол — 2–3 ночи, горошина, не веко. SPF каждый день, два пальца. Не обещать эффект завтра.
